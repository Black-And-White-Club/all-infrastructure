### ⚠️ argo-cd 9.x → 10.x Breaking Change

**`global.networkPolicy.create` default changed from `false` to `true`.**

In chart version 10.0.0, this parameter was flipped to align with upstream manifests and security best practices. The impact is that network policies will be automatically created on upgrade. If the cluster uses:
- A service mesh (Istio, Linkerd)
- CiliumNetworkPolicy instead of standard NetworkPolicies
- Custom network policy controllers

...this may conflict with existing policies or break inter-component communication. **Verify that `charts/argo-cd/values.yaml` sets `global.networkPolicy.create: false` if needed before syncing.** See: https://github.com/argoproj/argo-helm/blob/main/charts/argo-cd/README.md

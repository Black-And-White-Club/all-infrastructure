### 4. CERT-MANAGER — Breaking changes in v1.21

Included in updates above. The jump from `v1.16.2` → `v1.21.1` crosses several minor versions. Breaking changes in **v1.21** specifically:

1. **Default `tokenrequest` RBAC removed from Helm chart** — The chart no longer creates a default `Role`/`RoleBinding` for `serviceaccounts/token: create`. If `serviceAccountRef.name` points at the cert-manager controller ServiceAccount, you must create your own binding or migrate to a dedicated ServiceAccount.
2. **`cert-manager-edit` ClusterRole restricted** — `create` permission for `challenges.acme.cert-manager.io` and `orders.acme.cert-manager.io` removed. If any tooling creates these resources directly, explicit RBAC grants are required.
3. **Metrics port name and path Helm values removed** — Review `charts/cert-manager/values.yaml` for any `prometheus.servicemonitor.port` or `prometheus.servicemonitor.path` references that may no longer be valid.

Also: a HIGH-severity security fix ([GHSA-8rvj-mm4h-c258](https://github.com/cert-manager/cert-manager/security/advisories/GHSA-8rvj-mm4h-c258)) is included. Upgrading is strongly recommended on security grounds.

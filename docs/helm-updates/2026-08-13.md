### ⚠️ PostgreSQL Safety Reminder

**DO NOT** update `argocd/apps/frolf-postgres.yaml` if the latest Bitnami postgresql chart
ships a different PostgreSQL **major** version (e.g., PG 16 → PG 17).
A PG major version bump causes `initdb` to run on startup, **wiping the entire frolf database**.
This already happened once. Verify `app_version` shows the same PG major before updating.

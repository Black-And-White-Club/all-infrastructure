## ⚠️ Breaking Changes / Manual Review Required

### 🔴 argo-cd: 9.5.14 → 10.9.2 — ArgoCD v2 → v3 (MAJOR APPLICATION UPGRADE)

This is the **most impactful change in this batch**. Chart 10.x deploys ArgoCD v3, a major application version upgrade.

**Key breaking changes:**

1. **NetworkPolicy default changed** — `global.networkPolicy.create` flipped from `false` to `true`. Each ArgoCD component now gets a default-deny-ingress NetworkPolicy. **If you use a service mesh, external tools that access repo-server (e.g. kubechecks, Renovate), or rely on the previous open networking behaviour, you must add `global.networkPolicy.create: false` to `charts/argo-cd/values.yaml` before this syncs.**

2. **OCI registry TLS stricter** — Helm v4 (bundled in ArgoCD v3.5) requires plain HTTP OCI registries to be explicitly flagged with `--insecure-oci-force-http`. Any `helm` or OCI app source that uses HTTP without TLS will fail.

3. **GnuPG key verification replaced** — The GnuPG feature is replaced by "Source Integrity." Existing GnuPG-signed repo configs must be migrated.

4. **SSH host key verification tightened** — ArgoCD upgraded go-git, which tightens SSH host-key verification for repos without explicit credentials.

**Recommended action:** Review `charts/argo-cd/values.yaml` and check if `global.networkPolicy.create: false` is needed. Read the [ArgoCD v3 upgrade docs](https://argo-cd.readthedocs.io/en/latest/operator-manual/upgrading/3.4-3.5/) and plan a maintenance window.

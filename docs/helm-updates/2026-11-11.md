Breaking change in 8.0.0: **CiliumNetworkPolicy support was dropped** (PR #6183). If the cluster uses Cilium CNI with NetworkPolicies managed via this chart, those policies will no longer be deployed after the upgrade.

**Action:** Verify no `ciliumNetworkPolicy` values are set in `charts/kube-state-metrics/values.yaml`.

### cert-manager: v1.16.2 → v1.21.1

Breaking change in **v1.21.0**: The default Role and RoleBinding that allowed the controller to create tokens for its own ServiceAccount were removed from the Helm chart. This may affect non-standard setups that relied on those permissions.

v1.21.1 is a bug-fix release that addresses a controller panic, log spam regression, Issuers stuck at `InvalidSolver`, and a Gateway API values typo. All users should upgrade.

**Release:** <https://github.com/cert-manager/cert-manager/releases/tag/v1.21.1>

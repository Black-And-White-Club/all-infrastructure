### cert-manager: v1.16.2 → v1.21.1

**Release notes** ([view on GitHub](https://github.com/cert-manager/cert-manager/releases/tag/v1.21.1)):

cert-manager v1.21 has **three breaking changes**:

1. **Default `tokenrequest` RBAC removed from Helm chart** — The chart no longer creates a default `Role`/`RoleBinding` for `serviceaccounts/token: create`. If you use `serviceAccountRef.name` pointing at the controller ServiceAccount (e.g. for Route53/Vault IRSA), you must create your own RBAC or migrate to a dedicated ServiceAccount.

2. **Restrict Challenge and Order RBAC in `cert-manager-edit` ClusterRole** — `cert-manager-edit` no longer grants `create` for challenges or write access to orders. (Was already shipped in v1.20.3/v1.19.6 — only breaking if upgrading from v1.16–v1.19.5.)

3. **Metrics configuration changes** — Review the metrics values in your cert-manager Helm values before upgrading.

Intermediate highlights: v1.17 added initial Gateway API v1 support; v1.18 changed `Certificate.Spec.PrivateKey.RotationPolicy` default to `Always`; v1.19 added ACME certificate profile support; v1.20 added AWS IAM Vault auth.

### ⚠️ cert-manager Breaking Changes (applied — review before merging)

cert-manager was updated from v1.16.2 → v1.21.0 (spanning 5 minor versions). Known breaking changes along this path:

- **v1.21.0**: The Helm chart no longer creates the default Role and RoleBinding that allows the cert-manager controller to create tokens for its own ServiceAccount. If `serviceAccountRef.name` points at the controller ServiceAccount anywhere in your config, create your own Role + RoleBinding before upgrading.
- **v1.20.x**: `cert-manager-edit` ClusterRole no longer grants create/patch/update for `challenges.acme.cert-manager.io` or `orders.acme.cert-manager.io`.
- **v1.20.0**: CRDs use `selectableFields` which are not supported on Kubernetes < 1.31. Ensure the cluster is on k8s 1.31+ before merging.

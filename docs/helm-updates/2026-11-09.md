### ⚠️ prometheus-node-exporter: 4.55.0 → 5.0.0 (MAJOR chart bump)

**Chart v5.0.0 breaking change:** Adds restrictive security context defaults:
- `containerSecurityContext.allowPrivilegeEscalation: false`
- `containerSecurityContext.capabilities.drop: [ALL]`
- `containerSecurityContext.seccompProfile.type: RuntimeDefault`

If your node-exporter values set `privileged: true` or add `CAP_SYS_ADMIN`, also set
`allowPrivilegeEscalation: true` — the API server rejects the combination otherwise.
To revert to previous behaviour, set the new keys to `null` in `charts/prometheus-node-exporter/values.yaml`.

App version: 1.11.1 → 1.12.1 (minor).

**GitHub releases:** https://github.com/prometheus-community/helm-charts/releases?q=prometheus-node-exporter-5
